## Run locally
افتح `index.html` مباشرة في المتصفح.

أو:
```bash
python -m http.server 8000
```

ثم افتح:
`http://localhost:8000`

## Publish on GitHub
1. أنشئ Repository باسم مثل `coins-storefront-portfolio`.
2. ارفع جميع الملفات من حسابك.
3. نفّذ Commit من حسابك أنت.
4. فعّل GitHub Pages من Settings > Pages.
5. احتفظ برابط الـRepository ورابط النسخة المنشورة.
